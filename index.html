Which columns are needed?

Both files need: supplier GSTIN, invoice number, invoice date, taxable value, and IGST / CGST / SGST. Portal names work too ("GSTIN of supplier", "Invoice number", "Taxable Value", "Integrated Tax", "Central Tax", "State/UT Tax"). Optional: supplier name, document type (Invoice / Credit Note). Save the GSTR-2B B2B sheet from the portal Excel as CSV. To test accuracy, add an answer key with columns _id, expected, pair_group (see the test pack).

Noise included: invoice numbers in 7 formats, paise rounding, duplicates typed differently, GSTIN typos, the same invoice number used by two vendors, and a new financial-year format v2 had never seen.

What v1 got wrong, and the v2 fix

  • Paise rounding flagged as value mismatch → tolerance of ₹2 or 0.1%
  • Same invoice number, other vendor, matched wrongly → GSTIN fallback only after same-vendor matching, max 2 characters different
  • Duplicates typed differently missed → detect on normalised number
  • "0012" vs "12" not matched → strip leading zeros

All 34 remaining misses are safe misses: flagged for review, never wrongly marked "credit safe". Most are a financial-year format ("26-27" vs "2026-27"): exactly the long tail the AI engine is there to handle, with guardrails checking every call.
